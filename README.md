# Procedurally-Generated-Dungeon

## How to run the game

Install [Node.js](https://nodejs.org/) (includes npm).

Install dependencies:

```bash
npm install
```

Start the game

```bash
npm run dev
```

Open the local URL shown in the terminal

## Controls

Left mouse click: Move the character towards the clicked location.
